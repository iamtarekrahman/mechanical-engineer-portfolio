# Images

Drop your real photos here to replace the blueprint placeholders. No code
changes are needed — the site uses the same paths and will render your photo
as soon as the file exists.

- `profile.jpg` — personal / ID photo (portrait, ~4:5, e.g. 800×1000).
- `tesla-turbine.jpg` — Tesla turbine prototype (landscape, ~4:3, e.g. 1200×900).

Until these files are added, a hatched blueprint placeholder is shown in each slot.
